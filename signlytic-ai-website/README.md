# Signlytic AI - Portfolio Website

Professional portfolio website for the BSL AI Recognition & Translation project.

## Features

- **Modern Design**: Dark theme with gradient accents
- **Embedded Demo**: HuggingFace Spaces Gradio app
- **Performance Metrics**: Animated counters and tables
- **Responsive**: Mobile-friendly layout
- **SEO Optimized**: Meta tags and Open Graph

## Deployment

### Deploy to Vercel

1. Push to GitHub:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/Iyanuoluwa007/signlytic-ai-website.git
git push -u origin main
```

2. Deploy on Vercel:
   - Go to [vercel.com](https://vercel.com)
   - Import your GitHub repository
   - Vercel auto-detects Next.js and deploys

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

- **Framework**: Next.js 14
